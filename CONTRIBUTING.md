# Contribuer

- Une branche et une PR par lot ; CI verte (format, clippy sans avertissement, tests Linux et Windows, cargo-deny,
  recherche de secrets) avant fusion.
- Messages de commit en français, forme `type(portée): résumé` (`feat`, `fix`, `docs`, `chore`, `test`, `refactor`).
- **Neutralité** : le dépôt est tenu comme public. Aucune donnée réelle (nom d'organisation, de personne, d'hôte,
  adresse interne, nom de document, export de journal). Exemples et jeux d'essai **fictifs** : `example.org`,
  `192.0.2.0/24`, `EXEMPLE`, imprimantes et utilisateurs inventés. Rien de propre à un site dans le code ni dans les
  valeurs par défaut : la configuration le fait.
- Dépendances : licences permissives seulement (`deny.toml`).
