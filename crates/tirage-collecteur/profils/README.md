# Profils de copieurs / Printer profiles

Un fichier `<nom>.toml` par marque, intégré automatiquement à l'exécutable, et son relevé d'essai
`essais/<nom>.toml` (obligatoire : la CI le vérifie). One file per brand, each with its test sample.
